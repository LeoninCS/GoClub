# GoClub

GoClub 是一个面向 Go 后端面试的知识库，整理高频面试真题、八股总结、学习资源和视频配套文章，用 GitHub 协作维护，PR 合并后自动部署。

## 怎么用

- 正在准备面试：从「面试真题」和「八股总结」开始
- 找学习路径、资料和网站：看「资源荟萃」
- 想投稿面经：先读[面经投稿流程]({{< relref "/docs/blog/提交流程.md" >}})，用 AI 整理并人工检查后，再通过 Issue 表单提交
- 想补充其他内容或纠错：读一下[投稿与提交流程]({{< relref "/docs/blog/提交流程.md" >}})，可以使用 AI 整理后提 PR，也可以手动修改并提交 PR
