# 超級の新人 字节 Agent 开发实习一面

## 背景

boss 上有 hr 让发简历，看着挺对口，一看居然是字节，于是抱着试试看的心理投了一下，没想到一周后居然约面了。

## 面试内容

### 自我介绍与项目

1. 上来先自我介绍
2. 问一下实习状况，大一就可以实习了吗？
3. 询问对 Agent 自进化的理解
4. Agent 自进化最后的产物，提取的标准是怎样的？提取内容质量的好坏是怎样评估的？
5. 用于做 Agent 自进化的数据从哪来的？怎么获得高质量数据的？怎么判断它是高质量数据？
6. Agent 自进化在沙箱环境做的目的是怎么考虑的？为什么一定得在沙箱环境做？
7. 沙盒快照和回滚，快照的选择时机大概是怎样做的？
8. 沙盒的安全性有了解吗？它是怎么做的隔离？
9. 评测体系是怎么做的？
10. Harness 层现在是怎么构建的？
11. 举实际例子来说说怎么从头到尾改进评测的？
12. 做评测 Harness 的目的是为了做什么？
13. 构建的评测体系是如何和业务内的实际场景去应用的？
14. 评测是从哪些维度去做的，评判的标准是什么？
15. 项目经历里面 Hello Agent 智能体的架构，为什么把它转化为 Go 语言？出于什么考虑？
16. 使用 Go 语言重写其中遇到什么问题？
17. 说一下模块和模块的依赖关系？这些模块是怎么做的？

## 算法

### 小于 n 的最大数

数组 A 中给定可以使用的 1~9 的数，返回由 A 数组中的元素组成的小于 n 的最大数。

例如 A={1, 2, 4, 9}，n=2533，返回 2499。
