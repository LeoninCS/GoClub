## NoSQL（例如 MongoDB）和关系型数据库（例如 MySQL）的区别

- NoSQL 是非关系型数据库，特点是 schema 灵活。
- NoSQL 对固定表结构依赖弱，易于水平扩展，适合海量数据和高并发场景。
- MySQL 是关系型数据库，表结构明确，支持 SQL、事务、约束和复杂查询。
- MySQL 更适合强一致交易、复杂关联查询和结构化业务数据。
- MongoDB 这类 NoSQL 更适合文档型数据、快速迭代、字段变化频繁和水平扩展场景。
