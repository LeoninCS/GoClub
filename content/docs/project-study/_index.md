# 项目学习

## 学习工具

- [视频 Feed 流系统（medium）](./study-feed/)：7 天拆解，含知识准备、面试模拟与场景还原。
- [视频 Feed 流系统（hard）](./study-feed-hard/)：15 天拆解，基于 `LeoninCS/GCFeed`。
- [GCFeed 面试问题清单](./gcfeed-interview/)：架构、Feed 链路、缓存、热榜与部署追问。
- [比特币 PoW 区块链](./study-blockchain/)：10 章共识协议拆解。
- [Learn Claude Code（中文版）](https://learn.shareai.run/zh/)：从调用模型和执行工具的循环开始，逐步加入权限检查、上下文压缩和多 Agent 协作，动手实现一个编程助手。
